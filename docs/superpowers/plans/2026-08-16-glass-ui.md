# Glass UI Design System Pass — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle the entire `app/components/ui/` kit plus app chrome (header, sidebar, login) into a cohesive subtle-glass aesthetic — translucent surfaces, backdrop blur, hairline borders, inner top highlights — while keeping the Tailwind v4 token architecture, all component APIs, variant names, and accessibility behavior unchanged.

**Architecture:** Add four glass color tokens (`glass`, `glass-strong`, `glass-border`, `glass-highlight`) to `app/app.css` with dark/light values, plus a faint ambient radial-gradient on `body` so translucent panels have something to frost. Then restyle each component in `app/components/ui/` and the chrome components with the glass recipe. A shared `.glass-panel` utility class avoids duplicating the compound shadow + blur + hairline border across panels.

**Tech Stack:** Tailwind CSS v4 (token-based), React 19, React Router 8, TypeScript. No new dependencies.

## Global Constraints

- No new runtime dependencies.
- Do NOT change any component props, variant names, ARIA attributes, or behavior — only className/style strings and CSS.
- All mode-specific styling must live in CSS variables; no hardcoded `dark:`/`light:` utility sprawl.
- Keep the blue accent (`#3b82f6` dark / `#2563eb` light) unchanged.
- Keep all existing transitions, focus-visible rings, disabled states, and active-press scales.
- All UI text stays English.
- Per-task verification: `npm run typecheck` must pass, plus a visual check via the dev server (`npm run dev`). No unit tests exist for UI styling; final `npm run build` and `npm test` run in Task 10.

```css
      rgba(2, 132, 199, 0.05),
      transparent 70%
    );
}

/* Shared glass panel look: translucent + blur + hairline border + depth.
   Defined in @layer components so Tailwind utilities (which live in the
   utilities layer, declared later) can override it on hover/focus. */
@layer components {

    border: 1px solid var(--glass-border);
    background-color: var(--glass);
    -webkit-backdrop-filter: blur(12px);
    backdrop-filter: blur(12px);
    box-shadow:
      0 1px 2px rgba(0, 0, 0, 0.25),
      inset 0 1px 0 var(--glass-highlight);
  }
}
```
