# UniRoute AI Gateway — Master Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Membangun UniRoute, AI Gateway Proxy & Router single-buffer, menggabungkan berbagai API AI Provider ke 1 endpoint universal (`/v1/chat/completions`) dengan streaming SSE zero-buffering, load balancing 6 strategy, dan dashboard admin-only.

**Architecture:** React Router v8 (Framework Mode) + Bun + SQLite. Inti adalah pipeline 5-stage server-side: **Route → Translate → Execute → Stream → Record**. Semua logika server di `app/.server/` (tidak pernah di-bundle ke client). UI dashboard admin memakai Tailwind CSS.

**Tech Stack:** Bun, React Router v8, React 19, TypeScript, ESM-only, SQLite (`bun:sqlite`), Tailwind CSS.

---

## Global Constraints

Dari UniRoute_PRD_v7.md §4–§6, §8, §15:

- Baseline: Node 22.22+, React 19.2.7+, Vite 7+, ESM-only.
- Package: gunakan `react-router` (bukan `react-router-dom`). Import DOM-specific dari `react-router/dom`.
- File routes: `flatRoutes()` dari `@react-router/fs-routes`.
- Server-only code di `.server/` — tidak pernah di-bundle ke client.
- Env vars (4): `PORT=3000`, `BASE_URL=http://localhost:3000`, `PASSWORD=CHANGEME`, `DATABASE_URL=./data/uniroute.db`. `PASSWORD` wajib overridable via env.
- Semua route UI protected (wajib login). Hanya `/login` public.
- `/v1/chat/completions` terima format OpenAI, streaming SSE zero-buffering (dilarang akumulasi response ke array/string).
- Execute: timeout 120s, retry maksimal 1x.
- Kompresor: `Bun.spawn('./bin/rtk')` → `./bin/caveman`, timeout 5s/subprocess, fallback ke prompt asli + log warning.
- Graceful shutdown ≤ 5s saat SIGTERM. Build size < 10 MB.
- Naming: kebab-case untuk file & komponen.
